# FLASH - Deployment Guide

Production targets:
- **Backend** -> Render (Docker, free tier)
- **Frontend** -> Cloudflare Pages (static, free)
- **Database** -> Neon PostgreSQL (free tier, EU region)
- **Domain** -> Cloudflare DNS (free SSL)

---

## 1. Backend on Render

### 1.1 Prerequisites

- GitHub repo pushed to `main`
- Render account (free tier)
- Neon PostgreSQL connection string

### 1.2 Deploy via Blueprint (recommended)

1. Render Dashboard -> **New** -> **Blueprint**
2. Connect GitHub repo
3. Render auto-detects `render.yaml`
4. Fill in secret values when prompted:
   - `DATABASE_URL` (Neon connection string with sslmode=require)
   - `BACKUP_KEY` (generate: node -e "console.log(require('crypto').randomBytes(32).toString('base64'))")
   - `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `GEMINI_API_KEY` (optional)
   - `ADMIN_TOKEN` (generate: node -e "console.log(require('crypto').randomBytes(24).toString('hex'))")
5. Click **Apply**

### 1.3 Run migrations

After first deploy, from the Render Shell:

    npm run migrate
    npm run seed
    npm run seed:atlas
    npm run admin:setup -- owner@yourdomain.com "Your Name"

### 1.4 Verify

    curl https://flash-backend.onrender.com/health
    curl https://flash-backend.onrender.com/ready

Expected:
- `/health` -> ok: true (fast, no DB)
- `/ready` -> ok: true, db: { reachable: true }

## 2. Frontend on Cloudflare Pages

1. Cloudflare Dashboard -> **Pages** -> **Create**
2. Connect GitHub repo
3. Build settings:
   - **Framework preset:** None
   - **Build command:** (leave empty)
   - **Build output directory:** `frontend/dashboard`
4. Deploy

Add a redirect rule: / -> /FLASH.html

---

## 3. Neon Database

1. Create account at https://neon.tech
2. Create project: flashdb, region **Frankfurt (EU)**
3. Copy connection string -> paste into Render DATABASE_URL
4. Connection limit: max=10 (already in db.ts)

---

## 4. Required Environment Variables

- `DATABASE_URL` - Neon Postgres
- `AUTH_SECRET` - 64-char random (auto-generated by Render)
- `BACKUP_KEY` - 32-byte base64
- `ADMIN_TOKEN` - 32-char hex
- `GROQ_API_KEY` - for AI (free tier: 1000 req/day)
- `OPENROUTER_API_KEY` - fallback

---

## 5. Post-Deploy Checklist

- [ ] /health responds in < 50ms
- [ ] /ready shows correct migration count
- [ ] Admin login works with x-admin-token
- [ ] Player OTP flow works
- [ ] AI chat returns responses (if GROQ key set)
- [ ] CORS allows frontend origin

---

## 6. Monitoring

- **Uptime:** UptimeRobot (free) -> ping /health every 5 min
- **Logs:** Render Dashboard -> Logs
- **Neon metrics:** Neon Dashboard -> Usage
