# 01 — نظرة عامة على المشروع

## 1.1 هوية المشروع

- **الاسم:** FLASH
- **النوع:** منصة تدريب معرفي تعمل في المتصفح
- **المسار الجذري:** `D:\Flash\`
- **اللغة:** EN + AR (دعم RTL كامل)
- **النموذج التجاري:** مجاني + مفتوح المصدر

## 1.2 الغرض الأساسي

منصة تدريب معرفي تحتوي على **36 لعبة صغيرة (mini-games)** عبر **9 مجالات معرفية**. كل لعبة مبنية على **paradigm علمي حقيقي** مع citation أكاديمي موثق. المنافس المباشر: Lumosity / Peak / BrainHQ.

## 1.3 المشكلة التي يحلها

- المنصات الحالية مدفوعة ومبالغة في ادعاءاتها العلمية
- المحتوى ثابت (المستخدم يحفظ الإجابات)
- تجربة موحّدة للجميع (one-size-fits-all)
- لا يوجد تحليل عميق للأداء

## 1.4 الجمهور المستهدف

فئتان:
- **بالغون 25-45** يبحثون عن دليل قابل للقياس على التحسن
- **طلاب** يريدون إحساسًا بالتقدم

كلاهما متشكك في ادعاءات "ألعاب الدماغ" — يحتاجان أداة تبدو جدية لا طفولية.

## 1.5 الأهداف الرئيسية

1. **قابلية القياس**: كل جلسة تُنتج بيانات (accuracy, median RT, RCS)
2. **المحتوى اللانهائي**: AI يولّد أسئلة جديدة لكل لعبة
3. **الصعوبة التكيفية**: نظام يعدّل المستوى حسب أداء المستخدم
4. **AI Coach**: مساعد ذكي يعرف المستخدم ويشرح ويقترح
5. **ثنائية اللغة**: EN + AR من اليوم الأول

## 1.6 الرؤية طويلة المدى

- منصة تدريب معرفي مجانية وعلمية
- نظام مزامنة متعدد الأجهزة (Sync Protocol)
- مستخدمون حقيقيون (Auth)
- نشر على السحابة (Render + Cloudflare)

## 1.7 المبادئ الأساسية

| المبدأ | التفصيل |
|---|---|
| **Vanilla JS فقط** | مفيش React/Vue/Svelte |
| **مفيش build step** | مفيش Vite/Webpack |
| **مفيش TypeScript في الفرونت** | TypeScript في الباك فقط |
| **كل لعبة self-contained** | تشتغل من `file://` |
| **لا framework lock-in** | كل حاجة قابلة للتعديل يدويًا |
| **الشفافية العلمية** | كل لعبة لها citation حقيقي |
| **الجدية في التصميم** | مفيش emojis، مفيش confetti، مفيش "Great job!" |

## 1.8 ما يميز المشروع

1. **36 لعبة** كل واحدة مع paradigm علمي حقيقي
2. **AI حقيقي** — مش مجرد recommendations
3. **مصدر مفتوح بالكامل**
4. **EN + AR مع RTL native**
5. **يعمل offline** (في الفرونت الأصلي)
