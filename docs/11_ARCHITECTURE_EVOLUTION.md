Architecture Evolution
Phase 1: Web-Only (Monolithic)
Architecture: Single index.html loading all JS files globally. Backend on localhost:3000.

Reason: Fast prototyping and zero build step.

Issues: Global namespace pollution, hard to maintain. Games ran in iframes but relied on window.parent.postMessage.

Phase 2: Modular Web (Dashboard v2)
Architecture: Split into frontend/dashboard/ (core UI) and frontend/games/ (42 isolated games). Each game has its own 8 files. Shared systems (i18n.js, settings.js, flash-stages.js) handle universal logic.

Reason: Separation of concerns. Prevent a single bug from crashing the whole app.

Issues: Still heavily tied to file:// and local localhost.

Phase 3: Mobile Wrap (Capacitor - Current)
Architecture:

Isolated the web assets into a public/ directory.

Used Capacitor to wrap public/ into a native Android WebView.

Added @capacitor/preferences to replace raw localStorage.

Added @capacitor/app for hardware back button.

Disabled AI and live backend calls (Offline Mode) on mobile.

Reason: Preserve the 42 Vanilla JS games without rewriting them in React Native.

Rejected Alternatives: React Native (would require rewriting 42 games from scratch).

17_TACIT_KNOWLEDGE.md
Tacit Knowledge and Project Constraints
Windows Case-Insensitivity: PowerShell Move-Item treats 01_ARCH and 01_arch as identical. Avoid nested directory renames.

Android Java Quirks: Always set JAVA_HOME to Android Studio's JBR (Java 21). Do not rely on system Java (often 8 or 25).

ADB Ghost Devices: adb devices often shows offline devices after a crash. adb kill-server and killing qemu-system-x86_64.exe is mandatory.

Capacitor Flags: npx cap run android --livereload fails in Capacitor 8. Use -l.

No Frameworks: User strictly enforces Vanilla JS. Do not introduce React, Vue, or Tailwind.

Full Files Only: User expects complete file replacements, not partial diffs.

L4 Claims: Never mention ADHD, IQ, or clinical therapy in AI outputs. The backend validator enforces this.
